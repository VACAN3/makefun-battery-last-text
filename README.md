One line (123 characters): the phone battery's last text to the charger it waited for all day — a fake martyrdom for the laptop, undone by two words at the end.

> you spent all day charging the laptop. i die at 1% so the macbook can live at 100%. tell it i said it was worth it. i lied.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (falls back to `./output/entry.txt` when `/output` is not writable) and prints its character count.
